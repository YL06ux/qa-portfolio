
# Checklist de Testes – Login de Usuário

**Funcionalidade:** Login de usuário  
**Objetivo:** Cobrir os principais cenários de teste para a tela de login.

## Checklist de testes

- [ ] Acessar a página de login e verificar se carrega corretamente.
- [ ] Realizar login com e-mail e senha válidos.
- [ ] Realizar login com e-mail inválido (sem @ ou domínio).
- [ ] Realizar login com senha incorreta.
- [ ] Tentar login com campo vazio (e-mail em branco).
- [ ] Tentar login com campo vazio (senha em branco).
- [ ] Verificar se a mensagem de erro é exibida para credenciais inválidas.
- [ ] Verificar se o foco do cursor vai para o primeiro campo ao abrir a tela.
- [ ] Verificar se o link “Esqueci minha senha” está visível e clicável.
- [ ] Verificar o layout (alinhamento, fontes, cores e botões).
- [ ] Verificar o comportamento em dispositivos móveis (responsividade).
