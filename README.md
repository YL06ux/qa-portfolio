# QA Portfolio – Yan Lima

Portfólio de estudos e práticas em Quality Assurance (QA).

## Sobre o projeto

Este repositório apresenta meus estudos práticos em testes de software, com foco em testes manuais, documentação de qualidade e automação de testes.

## Objetivo

Desenvolver habilidades para atuar como QA Júnior ou QA Trainee, aplicando boas práticas de testes em projetos reais e de estudo.

## Conteúdos do portfólio

- Casos de teste
- Checklists de testes
- Bug reports
- Testes positivos e negativos
- Testes do módulo de login
- Testes de API
- Automação de testes com Python e Playwright
